# 📊 AR Portfolio Analyst

A modern **portfolio analysis web application** built with React and TypeScript.  
It provides clean visualization and insights for tracking financial assets in a responsive dashboard UI.

## 🚀 Features

- 📈 Portfolio tracking and analysis  
- 📊 Interactive charts and data visualization  
- ⚡ Fast and responsive interface  
- 🎯 Clean, minimal, and modern UI design  
- 🔄 Real-time data updates (if integrated)

---

## 🛠 Tech Stack

- React  
- TypeScript  
- Vite  
- Tailwind CSS  
- API integration
